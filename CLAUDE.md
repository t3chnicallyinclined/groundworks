# Rules for sessions in this repo

1. **No client or matter data in this repo.** Not in code, docs, notes, tests, fixtures, commit messages or issue text. If a lesson comes from a private instance, record the lesson in generic form and the measured number, never the material.
2. **Verify before claiming.** A paper, repo, product or feature is described only after reading it (fetched page, cloned repo, official docs). Search summaries and aggregator pages are pointers, not sources. Tag claims CONFIRMED (read in a primary source or measured), INFERRED (reasoned from confirmed facts), or UNKNOWN.
3. **Never claim novelty on a search result alone.** Say what was searched and that absence is not proof.
4. **Gates live in the datastore and are tested both ways.** A probe suite must show the gate rejecting what it should and accepting what it should; a gate that only rejects, or only accepts, is broken.
5. **Checks that pass by default are the main enemy.** Errors raise; dry runs say "NOT EXECUTED"; a batch that returns fewer results than statements is a failure; report the unflattering number next to the flattering one.
6. **The evaluator is human-owned.** Agents may add regression entries; they may not remove, weaken or edit existing entries, gates, evidence ladders or privacy rules.
7. **Licensing.** Follow the policy table in `docs/LICENSING.md` section 6: permissive licenses (MIT, Apache-2.0, BSD, ISC, PostgreSQL, public domain) may be used and adapted with notices; weak copyleft only as unmodified dependencies; strong copyleft and source-available only after review; non-commercial or unlicensed material is ideas only. Every dependency, model and adapted item goes into `THIRD_PARTY_NOTICES.md` in the same change; `scripts/license_check.py` enforces it at commit. Licensing never blocks an optimization: when a feature needs a commercial license (for example SurrealDB schema control for tenants), record that the license must be bought before that feature ships.
10. **Other people's servers are off limits.** Throwaway test databases are started by this repo's tests and scripts on their own ports and stopped by PID only. Never kill a process by name (`taskkill /IM`, `pkill surreal`), never bind or connect to 8001, 8002 or 8003 (live databases belonging to other projects), and never "clean up" a port you did not open: report the stray PID instead.
9. **Universal engine.** XScholar is a general scholar for any corpus and goal; appeals is only the first instance. Engine code, tool names, contracts and docs use domain-free words (unit, label, claim, conclusion, critique, lens, panel); domain words live in instance adapters and `instance.yaml`. A new engine feature is tested with at least one non-legal synthetic instance.
8. **Record decisions** in `docs/DECISIONS.md` and dated reasoning in `notes/`.
