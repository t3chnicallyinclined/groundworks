# Groundworks brand

Decided 2026-10-29.

- **Logo:** `groundworks-logo.png`, a groundhog foreman coming up out of a taped-off hole, drawn as a blueprint,
  with the wordmark. `social-preview.png` is the 1280x640 crop for link previews.
- **Mascot:** `mascot.png`, the same groundhog cut out of the logo. New images of him start from this file as a
  reference image, so he stays the same character. He keeps his own colours (`tokens.json` -> `mascot`).
- **App icon:** `icon-*.png` and `favicon.ico`, his head and hard hat on a blueprint tile.
- **Colours** (`tokens.json` has light and dark assignments with contrast ratios):

| Role | Name | Hex |
|---|---|---|
| Brand surface | Blueprint Blue | `#0060A5` |
| UI primary | Electric Blue | `#0057FF` |
| Accent 1 | Hard-Hat Orange | `#F26B1D` |
| Accent 2, warnings | Caution Yellow | `#F5C518` |
| Text, outlines | Tape Black | `#1F1A17` |
| Light background | Paper | `#F7F3EC` |
| Dark background | Deep Night | `#0F1A2E` |

Rules: white text on Blueprint Blue (6.5:1) or Electric Blue (5.5:1); dark text on orange and yellow, never white;
never put the two blues on each other to signal anything (1.18:1).

The art was generated with Ideogram v3 and upscaled with Recraft. The small labels around the blueprint drawing
are not real words; a vector trace should replace them before print use.
